# 🎮 JanKenPon

> A classic Rock–Paper–Scissors game reimagined with a **manga-inspired UI**, animated characters, and a touch of video game flavor.  
> Built as part of *The Odin Project – Foundations Course*.

---

## 💡 Overview

This project was developed as part of **The Odin Project’s Foundations Course**.  
The original exercise was to build a simple Rock–Paper–Scissors game in JavaScript — but I decided to **take it a few steps further**.

Instead of keeping it in the console, I designed a **visual, game-like experience** with:
- Custom animated characters representing **Rock**, **Paper**, and **Scissors**
- Dynamic **health bars** to show game progress
- A playful **UI inspired by manga and retro fighting games**

---

## 🎨 Design & Approach

I wanted to use this project as an opportunity to **train my ability to manipulate CSS and HTML dynamically through JavaScript** — and to bring some creativity into front-end coding.

Here’s how I approached it:
- 🧩 I built the overall **graphic style** and **character concepts** with help from ChatGPT image generation.  
- 🧠 I created a simple user flow and model using PowerPoint (yes, I know — it’s hard to take the consultant out of the consultant! But I’ll switch to Figma for future projects). 
- 🎬 I added **basic animations** and transitions to make the experience feel alive.  
- 🎮 I focused on **DOM manipulation, event handling, and state management** in JavaScript.

This project was my first real dive into bringing logic and visuals together.

---

## ⚙️ Features

- 🧍 Character poses for **Rock**, **Paper**, and **Scissors**
- ❤️ **Health bars** to visualize the player and opponent’s remaining lives
- 🔁 Smooth round transitions with win/loss/draw feedback
- 🖱️ Interactive buttons with hover and click effects

---

## 🧠 Tech Stack

- **Languages:** HTML · CSS · JavaScript  
- **Tools:** PowerPoint (for initial wireframe and flow design) · ChatGPT (for assets and art direction)
